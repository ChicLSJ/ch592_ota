# CH592 OTA

**语言：中文（默认） | [English](README.en.md)**

CH592 BLE 燃气表广播器的 Home Assistant OTA 集成，通过 ESPHome 蓝牙代理在线升级固件、写入燃气值和采样阈值。

本仓库只保留更新说明。集成代码和固件源码不公开，不提供下载或安装文件。OTA 固件镜像和清单在 [ChicLSJ/ch592-gas-broadcaster](https://github.com/ChicLSJ/ch592-gas-broadcaster) 发布。

## 当前版本

| 项目 | 版本 |
|------|------|
| HA 集成 | 0.6.22 |
| 固件 | 1.5.6 |

1.5.5→1.5.6 实体 OTA 已成功：全程 126.8 秒，其中等待唤醒 77.2 秒（4 次尝试），上传和完整 CRC 约 50 秒。

## 使用

1. HA 发现新固件后，点击更新实体的“更新/安装”。
2. HA 下载并校验固件，然后在设备的普通广播窗口自动唤醒 OTA（固件 1.4.7 及以后），无需按 B。
3. 上传、校验、重启后，收到新版本普通广播，更新流程结束。

设备每分钟只有约 300 毫秒可连接的广播窗口，唤醒通常需要 1 到 2 分钟。旧固件首次升级仍需长按 B 约 10 秒。
